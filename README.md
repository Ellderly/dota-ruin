# Кто заруинил?

Локальный сайт для разбора матчей Dota 2: считает каждому игроку индекс руина 0–100 и показывает, кто виноват в поражении и почему.

## Запуск

Нужен Node.js 18+. Зависимостей нет.

```bash
npm start
```

Затем открой http://localhost:4777. На macOS можно дважды кликнуть `start.command`.

## Что вставлять

- ID матча или ссылку на матч (Dotabuff, OpenDota, Stratz);
- ссылку на профиль или account ID / SteamID64 — покажет последние матчи на выбор.

Данные берутся из открытого API OpenDota (у Dotabuff API нет) и кэшируются в `cache/`.
Лимит OpenDota без ключа — 2000 запросов в день; свой ключ можно передать через `OPENDOTA_API_KEY`.

## Структура

- `server.mjs` — сервер: статика, прокси OpenDota, кэш на диске.
- `public/analyzer.js` — движок оценки (все формулы, веса и пороги здесь).
- `public/items.js` — разбор сборки: угрозы врага и ответы на них под конкретного героя.
- `public/abilities.js` — разбор вражеских способностей: тип контроля, наведение, пробитие BKB, диспел.
- `public/hero-mechanics.js` — механики героев, заменяющие предметы (Counterspell, Rage, Doppelganger…).
- `public/probuild.js` — «Что лучше было собрать»: про-сборки текущего патча, поправки под пик, Аганим и Шард.
- `public/app.js`, `public/style.css` — интерфейс.
- `test/analyze.mjs`, `test/items.mjs`, `test/pro.mjs` — прогон в консоли: `node test/pro.mjs <match_id> [герой]`.

Методика описана на странице «Как считается» на сайте.

## Выложить на GitHub, чтобы кидать друзьям ссылку

Сайт умеет работать без сервера: если рядом нет `server.mjs`, страница сама ходит в OpenDota из браузера
(тот же код, те же формулы, тот же вид), а кэш и историю хранит в браузере у каждого посетителя.
Поэтому его можно разместить на GitHub Pages — бесплатно и без поддержки.

Быстрый способ — дважды кликнуть `publish.command` (нужен macOS и Homebrew). Скрипт установит `gh`, попросит один раз войти
в GitHub, создаст публичный репозиторий, включит Pages и зальёт код. Или вручную:

```bash
brew install gh && gh auth login
gh repo create dota-ruin --public --source=. --remote=origin
gh api -X POST repos/{owner}/dota-ruin/pages -f build_type=workflow
git push -u origin main
```

Через 1–2 минуты сайт будет по адресу `https://<твой-логин>.github.io/dota-ruin/`.
Автодеплой (`.github/workflows/pages.yml`) публикует папку `public/` при каждом пуше в `main`.

Что важно знать про версию на GitHub:
- у OpenDota лимит 60 запросов в минуту на один IP; первый разбор матча делает около 37 запросов, поэтому сайт сам придерживает запросы и пишет об этом;
- история матчей и кэш хранятся только в браузере посетителя (у каждого своя);
- свой API-ключ OpenDota в такой сайт класть нельзя — его увидит любой посетитель.
